# Currency Pulse

Красивый адаптивный сайт для отслеживания валют, криптовалют, конвертации, графика, сервисов и новостей.

## Быстрый запуск на Windows

1. Распакуй архив.
2. Запусти `START_SITE.bat` двойным кликом.
3. Браузер откроется сам: `http://localhost:3000`.

## Важно

В этой версии **не нужен `npm install`**. Сайт работает на чистом Node.js без внешних npm-пакетов, поэтому ошибка `npm ERR! ETIMEDOUT` больше не мешает запуску.

Если Node.js не установлен, батник сам откроет страницу загрузки Node.js.

## Ручной запуск

```bash
node server.js
```

или

```bash
npm start
```

## Источники данных

- ЦБ РФ — курсы фиатных валют к рублю.
- CoinGecko — курсы криптовалют.
- Frankfurter — дополнительный источник кросс-курсов.
- Google News RSS — новости по валютам и криптовалютам.

Если внешний источник временно недоступен, сайт автоматически включает резервные данные, чтобы интерфейс не зависал на загрузке.
